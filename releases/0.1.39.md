# Foil Studio 0.1.39 (43)

Release prepared on 6 October 2026 for Google Play production.

## What changed

- Clipart filters now use two rows: Collection spans the first row, with Search and Style together below it. The gallery has more space for browsing designs.
- Tool assignment is available per object through Object properties in the long-press context menu.
- The box wizard includes folding previews, flaps, and separate cut and fold paths.
- Expanded clipart collections provide cut, pen, and print-and-cut styles.
- Phone layouts for the box wizard, materials, and process settings have been improved.

## Validation

Static analysis passed. The Flutter regression suite passed 699 tests, with 11 optional tests skipped. Phone layout checks cover narrow screens, large text, landscape and the on-screen keyboard.

Google Play availability depends on its review and rollout status. Existing users receive the update through Google Play when approved and available to their device.
