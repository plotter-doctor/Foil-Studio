# Foil Studio 0.1.76

Release status, 17 October 2026: build 81 has been submitted for Google Play
production review. Google's checks and approval are pending; this is not yet a
confirmation that the update is available to everyone. The requested rollout is
100% in the existing supported countries, with automatic publication after approval.

The app download is now free. This update introduces three access levels:

- **Free:** draw, import and edit artwork; preview Box wizard and Craft wizard
  projects; retain one automatic recovery draft.
- **Basic unlock:** one permanent in-app purchase enables named project saves,
  the project library, export, printing and production plotter jobs.
- **Pro:** a monthly or yearly subscription includes Basic features while active
  and enables creating and regenerating Box wizard and Craft wizard projects.
  A separately purchased Basic unlock remains available after Pro ends.

Google Play displays the local price and handles payments. Starting prices in
Poland are 44.99 PLN for Basic, 12.99 PLN per month or 109.99 PLN per year for Pro.
In Germany they are 9.99 EUR, 2.99 EUR and 24.99 EUR respectively. Regional prices
and taxes vary. Pro renews until cancelled in Google Play; access continues for
the paid period after cancellation. There is no introductory trial.

## If you previously bought the app

Previous paid-app buyers can claim Basic at no extra cost. This requires a
one-time code redemption; the app does not automatically identify old app purchases.

1. Contact **pratanczuk@gmail.com** with your original Google Play app-order number.
   Send order information privately, not in a public issue or review.
2. After the original purchase is verified, support will provide a private,
   single-use Basic redemption code.
3. In Google Play, use **Payments & subscriptions → Redeem code** with the account
   you want to use for Foil Studio, then redeem the code.
4. Open Foil Studio's plans and choose **Restore purchases** using that account.

Claim your code before buying Basic again. The unlock is permanent Basic access,
not a Pro trial or subscription. The redemption deadline on an individual code
does not limit Basic after successful redemption. If an unclaimed code expires,
contact support for a replacement after purchase verification.

## Changes in this update

- Craft wizard variants for more project choices, alongside Box wizard.
- Raster artwork for printing, additional fonts, and tool, passes, pressure
  and speed settings per object.
- Double-tap artwork to reveal resize handles and use increased zoom for detail.
- A fix for saving or generating wizard projects when no recovery draft exists.
- Free/Basic/Pro purchase disclosures and restored access through Google Play.

Core purchase and subscription flows were tested on an Android phone using
Google's licence-test methods. The previous-buyer promo path was also validated:
zero-cost redemption granted Basic and access survived Restore purchases and an
app restart. Separate-device/clean-install restore remains pending; extended
live offline-boundary, clock-change, grace-recovery and running-job transitions
are not represented as completed live tests.

Updating preserves existing app data. Uninstalling or clearing storage can remove
private projects. A compatible physical plotter is required for production jobs.
