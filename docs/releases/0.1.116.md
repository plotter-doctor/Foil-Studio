# Foil Studio 0.1.116

This Android update brings the current multi-plotter catalogue, new design and
preparation tools, and clearer connections to the public release. Availability
depends on Google Play review and distribution.

Installation remains available on devices without location hardware. The
existing permission for Bluetooth discovery on older Android versions is retained.

## Find your plotter

Choose an exact vendor and model in Connection. The catalogue contains 72
profiles, including the two Generic HPGL/DMPL profiles. Named entries cover
Silhouette Cameo 1–5 and Portrait 1–3, VEVOR Smart 1–4 and selected KH/KI/SK
models, Graphtec CE LITE-50 and Craft Robo, selected Graphtec CE6000/CE7000/
CE8000/FC9000 variants, Roland, Summa, Skycut, USCutter, Teneth and HP.
The store description lists each included model. HP 7475A and 7550 Plus are
pen-plotting profiles. Functions and connection options depend on the model.

Graphtec CE LITE-50 has its own USB profile and work-area settings up to
498 × 3000 mm. Set force and speed on the plotter panel, and confirm completion
after movement finishes. This profile does not include ARMS registration.

Silhouette offers USB and BLE on supported models. VEVOR Smart uses supported
SPP/USB connections. Raw HPGL/DMPL profiles support matching bidirectional USB
printer interfaces, supported serial adapters or explicitly configured transparent
bridges, depending on the selected profile. After Android USB approval, the
requested connection continues automatically. BLE discovery selection is more
stable during refresh.

## Prepare printed and cut projects

Manual four-mark Print & Cut is available for FilmCut, Smart 1–4 and the included
Silhouette/Craft Robo profiles. Optical registration remains model-dependent.
AutoBlade is available in holder 1 on Cameo 3/4/5 and Portrait 2/3; Portrait 2
and Cameo 3 require confirmation of the installed tool. Manual Silhouette
Print & Cut uses one tool stage and manually set depth.

Use numeric dimensions in millimetres, align objects, fill sheets, prepare
stickers and QR labels, and organize material layers, including mirrored HTV.
Review generated paths before printing or production. Tracing from a file or
camera offers adjustable smoothing and path previews. Supported SVG/DXF and
eligible CDR curves can be edited; PDF/AI/EPS/CDR print import depends on file
content and supported features.

## Purchases and languages

The interface and help remain available in English, Polish, German and Spanish.
Free supports design/editing and previews. Basic is a permanent one-time purchase
for named saves, export, printing and production jobs. Optional monthly/yearly
Pro includes Basic while active and adds Box wizard/Craft wizard creation and
regeneration. Existing purchases are restored through the same Google Play
account. This release does not change prices or entitlements.

Earlier buyers of the paid download can still request Basic at no extra cost:
contact pratanczuk@gmail.com privately with the original Google Play app-order
number. After verification, redeem the supplied Basic code and restore purchases.
This is a one-time migration, not a repeated step after every app update.
