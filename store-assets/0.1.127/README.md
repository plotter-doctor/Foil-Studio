# Foil Studio 0.1.127 phone and tablet screenshots

Prepared 7 November 2026 for version **0.1.127 (148)**. This release is in Google Play review; approval and rollout are pending. Check the [version guide](../../docs/release-notes.md).

These eight PNGs are independent application renders, visually checked with the current app theme. Phone images are **1080 × 1920** and tablet images are **2880 × 1620**, all RGB PNGs without an alpha channel. They are prepared for the corresponding Google Play screenshot categories. The application is disconnected; sample artwork contains no customer project or private phone capture.
