# Foil Studio release notes

## 0.1.127 prepared for Google Play

**0.1.127 (148) is a release candidate prepared for Google Play; submission and availability are pending.** The current production release is 0.1.116 (137), published 6 November 2026. The [0.1.127 notes in English, Polish, German and Spanish](releases/0.1.127.md) describe cumulative changes since that version: layer material inheritance and review checks, active-project recovery, compact Prepare/Cut, a tablet layer tree, colour-preserving imports and knife-calibration corrections.
