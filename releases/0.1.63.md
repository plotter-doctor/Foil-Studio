# Foil Studio 0.1.63 (67)

Submitted to Google Play production on 10 October 2026. Google's automated checks
and review are pending. The release is configured for a full rollout after approval;
version 0.1.63 is not yet confirmed live.

## What changed

- Assign named tools to objects and override their speed, pressure and passes in Object properties. Materials are reference-only.
- Edit each tool group inside composite clipart and generated boxes. Pending edits stay available when switching between groups.
- Factory tool defaults use 2500 mm/min. Existing customized values are preserved.
- Bring objects to front or send them to back from the context menu, Edit or Object manager.
- Improved idle connection handling and optional Auto-connect for remembered supported connections. Reconnection never resumes machine motion.
- More compact Prepare screen, neutral In progress wording and recovery after canceled jobs.
- Updated menu icons and simpler project opening; the separate Open JSON action is removed.
- Current screenshots and a rewritten user manual covering design, box nets, tools, printing, manual Print & Cut alignment and troubleshooting.
