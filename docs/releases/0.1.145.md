## Compatibility and limits

Select the exact model, transport and loaded area. Home is a logical origin return, not limit-switch homing or an electronics restart. GCC uses manual tool changes and manual Print & Cut; automatic AAS, cut-off and hardware reset are not included. A simulator pass is not physical qualification. USB Device ID is optional, advisory and does not choose the command language. IEEE 1284.4 is not implemented. Full project export remains the recommended independent backup.
