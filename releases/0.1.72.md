## Changes since 0.1.63

- Default working pressure: Knife 180 PWM, Pen 150 PWM, Engraving and Scoring 250 PWM. Speed remains 2500 mm/min.
- New tools select their pressure by type. Editing pressure manually keeps that value when changing the type. Untouched factory profiles upgrade once; custom tools and saved object overrides remain intact.
- Saved Initial PWM and Initial duration settings provide two-phase tool lowering. Defaults are 320 PWM and 10 ms. Firmware G4 controls the initial phase before XY motion.
- Manual Tool down applies the entered working pressure. Directional jogs retain the tool's confirmed up/down state and pressure, without repeating the initial pulse.
- New objects start with the named 45-degree knife. The blade guide shows the supplied replacement set's yellow 30-degree, red 45-degree and blue 60-degree caps. Starting offsets are 0.25 mm for 30/45 degrees and 0.10 mm for 60 degrees; tune for the actual blade.
- Lossless repackaging reduces bundled artwork storage while retaining the existing Android architectures.

See the [updated tool and pressure guide](../docs/mobile/0.1.72/tool-pressure.md)
for setup, object overrides, manual jogging and migration behavior. The
[0.1.63 design/workflow manual](../docs/mobile/0.1.63/manual/README.md) remains the
reference for design, boxes, printing and object editing; the new guide supersedes
its tool-pressure and blade-default instructions.

PWM values are controller setpoints, not measured force. Validate settings on the
fitted head and material. The user's manual-jog regression check passed on 0.1.71;
that does not establish calibrated pressure or universal 10 ms lowering timing.
